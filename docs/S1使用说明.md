## 二、功能与操作

### 打开图片

| 方式 | 操作 |
|---|---|
| 按钮 | 左上角「打开」 |
| 快捷键 | `Ctrl + O` |
| 拖拽 | 把图片直接拖进窗口 |

### 查看与缩放

| 操作 | 效果 |
|---|---|
| **滚轮** | 以**光标位置为锚点**缩放（光标下的像素不动） |
| **拖拽** | 平移图片 |
| **双击** | 在「适应窗口」与「1:1 原始像素」间切换 |
| `+` / `-` | 放大 / 缩小 |
| `0` | 适应窗口 |
| `1` | 原始像素（100%） |
| `[` / `]` | 向左 / 向右旋转 90° |
| **方向键** | 平移（每次 60 px） |
| `Esc` | 回到适应窗口 |

### 支持的格式（S1 阶段）

| 格式 | 状态 |
|---|---|
| **JPEG**（.jpg / .jpeg） | ✅ 可用 |
| **PNG** | ✅ 可用 |
| 相机 RAW（CR3 / NEF / ARW / DNG / RAF / RW2 / ORF / SR2 / SRF） | ⏳ S3 阶段接入 LibRaw 后支持 |
| HEIC / HEIF | ⏳ S3 阶段支持 |
| WebP / TIFF / BMP / PSD | ⏳ 后续阶段 |

打开不支持的格式会显示明确的中文提示，**不会崩溃**。

### 状态栏信息

打开图片后底部显示：文件名、格式、尺寸（宽 × 高）、文件大小。
RAW 文件会额外显示 `RAW` 标记。

## 三、性能特性

| 特性 | 实现方式 |
|---|---|
| **大图不卡死** | 按目标尺寸解码。8000×6000 的图只解 2048 档，libjpeg 直���缩放解码，解码量降到约 1/8 |
| **缩放平移 60fps** | 用 CSS `transform` 走 GPU 合成，不重绘像素；拖拽用 `requestAnimationFrame` 节流 |
| **大图内存安全** | 像素走自定义二进制协议，不走 JSON（96 MB 的 RGBA 若走 JSON 会膨胀到 200 MB） |
| **快速切换不串图** | 每次解码带请求序号，过期结果被丢弃并立即释放 |
| **无内存泄漏** | 切换图片时显式 `close()` 上一张的 `ImageBitmap` |

## 五、已知限制（S1 阶段）

这些是**按计划留到后续阶段**的，不是缺陷：

| 限制 | 计划阶段 |
|---|---|
| 只支持 JPEG / PNG | S3 加 RAW/HEIC，S2 补 WebP/TIFF/BMP |
| 单图浏览，无缩略图网格 | S2 资源管理器 |
| 无 EXIF 详细信息（ISO/光圈/机型） | S2（Stage 1 已预留 `probe()` 全量 EXIF） |
| 无编辑功能 | S4 |
| 无批量处理 | S5 |
| 无加密容器 | S6 |
| 无 AI 检索 | S7 |
