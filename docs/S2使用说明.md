# PurePhotoExplorer S2 图库模式 —— 使用说明

> 更新：2026-10-24 · 界面以本说明为准；开发细节见《S2图像资源管理器开发手册》

## 一、启动

直接运行 `release/PurePhotoExplorer.exe`（或 `target/release/photovault.exe`）。
启动后进入**图库模式**，窗口最小尺寸 **1200 × 800**，可自由缩放/最大化。

- 图库是**持久**的：上次建的图库、侧栏状态都还在，跨会话保留。
- 左侧是资源管理器式的目录树：**我的电脑 → 盘符 → 目录**，懒加载。

## 二、浏览 ≠ 入库（两个概念，别混）

| 操作 | 含义 | 会不会写索引 |
| --- | --- | --- |
| **左键点目录** | 临时预览这个目录里的图片 | ❌ 不写索引、不写缓存 |
| **右键目录 →「加入图库」** | 正式入库（可建新图库或加进已有图库） | ✅ 写索引 + 写缩略图缓存 |

图库模式的范围是从**图库**里选的（`+` 左键 = 空图库，右键 = 智能图库预设）。

## 三、筛选

顶部四个标准下拉框（点开在按钮正下方，最多 13 行，超出滚动）：

| 下拉 | 筛什么 |
| --- | --- |
| 格式 | JPEG / PNG / HEIC / RAW … |
| 年份 | 按拍摄年份 |
| 相机 | 按相机品牌+机型 |
| 地点 | 按 EXIF GPS 解析出的城市（**离线地名库，不联网**） |

**AI 标签条**在标题右侧：

- 一级类目（艺术 / 人像 / 建筑 …）**每行固定 8 个**，不随窗口宽度重排；
- 点一级 → 进入二级类目（面包屑可点，点它 = 看整个一级）；
- 点二级 → 按这组标签筛选；
- **「无标签」是一级标签**，只在一级视图末尾出现；
- 标签条右端是**分析状态 + 设置齿轮**（阈值、词表、主题词）。

## 四、选择（多选）

| 操作 | 效果 |
| --- | --- |
| **单击缩略图** | **加选** —— 连续点几张就是多选，不用按 Ctrl |
| **再点已选中的那张** | 取消**本次全部**选择 |
| **点网格空白处** | 取消全部选择 |
| **Ctrl / Shift + 单击** | 只切换这一张（想单独摘掉某张时用） |
| **Ctrl + A** | 全选当前范围 |

选中后，标题右侧（**最后一个标签行的同一行右端**）会显示
`已选 N 张 · 总大小` 以及 `导出` / `标记` 两个按钮。

## 五、批量操作

**右键缩略图**（或在选中块上操作）：

| 菜单项 | 说明 |
| --- | --- |
| 评分 / 标记 | 写索引，不动文件 |
| 标签 | 给这批加/减标签 |
| 旋转 / 翻转 | **先旋转后翻转**，原子写回，Orientation 归 1 |
| 另存为… | 系统保存对话框；**同格式 = 直接复制字节** |
| 转换格式… | 真正重新编码（和「另存为」是两回事） |
| EXIF 摆正 | 只做 3/6/8（镜像类 2/4/5/7 会被拒绝） |
| 打印… | 打印预览 + 分页器 |
| **重命名…** | **单张**：直接在卡片文件名上改（文本全选，扩展名自动保留，Enter 提交 / Esc 取消）<br>**多张**：批量模板对话框，`{name}` = 原名、`{n}` = 序号（自动补零） |
| 删除到回收站… | 走 Windows 回收站（可恢复），**不是永久删除** |

⚠️ 批量重命名**不会覆盖**同名文件；改完会清掉旧缩略图缓存并刷新列表。

## 六、搜索

右上搜索框，匹配：**文件名 / 标签名 / 地点名 / 品牌 / 机型 / 镜头**。

- 空格分隔多个词是 **AND**（同时满足）；
- `%` `_` 会被当字面量处理，不会变成通配符。

## 七、快捷键（图库模式）

| 键 | 作用 |
| --- | --- |
| `Ctrl + A` | 全选 |
| `F5` | 重扫当前范围 |
| `L` | 给选中的图打标签 |
| `Ctrl + O` | 打开文件 |
| `Esc` | 取消编辑 / 退出单图浏览 |
| 双击缩略图 | 进入单图浏览 |

## 八、几个容易踩的点

1. **外部新增的文件不会自己出现** —— 放完新图按 `F5`，或切一下窗口焦点（会自动重扫，2 秒限流）。
2. **「移除目录 / 删除图库」只删索引和缓存，绝不碰原图**。
3. **删除照片是进回收站**，不是永久删除。
4. **RAW 只能另存为，不能覆盖原文件**（8bit 替换 14bit Bayer 不可逆）。
5. 图库里**没有标签**时，标签条整条不显示，选中块会回到标题行右侧显示。
