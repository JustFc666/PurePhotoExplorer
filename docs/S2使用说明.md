# PurePhotoExplorer S2 图库模式 —— 使用说明

> 更新：2026-10-26（按当前代码核对）· 界面以本说明为准；开发细节见《S2图像资源管理器开发手册》

## 一、启动

直接运行 `release/PurePhotoExplorer.exe`（开发模式：`cargo run` 或用 `scripts/pv-drive.py`）。
启动后进入**图库模式**，窗口最小尺寸 **1200 × 800**，可自由缩放/最大化。

- 图库是**持久**的：上次建的图库、侧栏展开状态都还在，跨会话保留。
- 启动默认停在**「我的电脑」**，主区不显示图片 —— 先选一个目录看看。

## 二、浏览 ≠ 入库（两个概念，别混）

| 操作 | 含义 | 会不会写索引 |
| --- | --- | --- |
| **左键点目录** | 临时预览这个目录里的图片 | ❌ 不写索引、不写缓存（标题旁显示「未加入图库」） |
| **右键目录 →「加入图库」** | 正式入库（建新图库 / 加进已有图库） | ✅ 写索引 + 写缩略图缓存 |

图库模式的范围是从**图库**里选的（`+` 左键 = 空图库，右键 = 智能图库预设）。

## 三、侧栏四块

| 分区 | 内容 |
| --- | --- |
| **文件夹** | 我的电脑 → 盘符 → 目录，懒加载；末位永远有「我的电脑」 |
| **图库** | 普通图库 + 智能图库（按规则自动生成，如「今年」「四星以上」「相机 RAW」） |
| **标签** | 全部人工标签 + 使用次数；点 = 按标签筛；右键可改名 / 删除标签 |
| **地点** | 离线地名库从 GPS 解析出的城市；点 = 只看在那拍的照片（只读） |

## 四、筛选

**入库模式**顶部有四个标准下拉框（点开在按钮正下方，最多 13 行，超出滚动）：
格式 / 年份 / 相机 / 地点。**浏览模式没有这一排**（未入库没有全库统计可比）。

### 标签条（标题右侧，固定两行）

```
全部 | 自然 建筑 人像 美食 动物 交通 | …      ← 第一行
      | 风景 夜景 街拍 花卉 室内 户外  | …      ← 第二行
```

- **每行固定 6 个，最多两行共 12 个**，放不下的用「…」展开（点「…」出浮层）；
- 点一级类目 → 进入它的二级类目（左侧「← 全部」返回，面包屑可点）；
- 点二级类目 → 按这组标签筛（命中任一即可）；
- 数字是**去重后的图片张数**；词表里有但没图的类目显示 0；
- **「无标签」**在左列，点它筛出还没打标的图；
- ⛔ 标签条不会自动铺满：右侧要给**人像条**留 80px。

### 人像条（标签条右侧）

- 显示当前范围内出现过的人物头像，**80×80 圆角方形**；
- **点头像 = 按这个人筛**（效果等同点标签）；
- 点末尾「更多图像」→ 打开**人像墙浮层**（不跳页）；
- 头像裁切走 EXIF 人脸坐标，`PAD = 0.06` 外扩，保留额头与下巴。

## 五、选择（多选）

| 操作 | 效果 |
| --- | --- |
| **单击缩略图** | **加选** —— 连续点几张就是多选，不用按 Ctrl |
| **再点已选中的那张** | 取消**本次全部**选择 |
| **点网格空白处** | 取消全部选择 |
| **Ctrl / Shift + 单击** | 只切换这一张（想单独摘掉某张时用） |
| **Ctrl + A** | 全选当前范围 |

选中后，**标题行右侧**显示 `已选 N 张 · 总大小` 以及 `导出` / `标记` 按钮。

> 浏览模式也支持多选与导出（导出/转格式/摆正/打印是**文件级**操作，不需要索引行）；
> 但评分 / 标记 / 删除 / 重命名需要索引记录，浏览模式下不提供。

## 六、批量操作

**右键缩略图**（或在选中块上操作）：

| 菜单项 | 说明 |
| --- | --- |
| 评分 / 标记 | 写索引，不动文件 |
| 标签 | 给这批加/减标签 |
| 旋转 / 翻转 | **先旋转后翻转**，原子写回，Orientation 归 1 |
| 另存为… | 系统保存对话框；**同格式 = 直接复制字节** |
| 转换格式… | 真正重新编码（和「另存为」是两回事） |
| EXIF 摆正 | 只做 3/6/8（镜像类 2/4/5/7 会被拒绝） |
| 打印… | 打印预览 + 分页器 |
| **重命名…** | **单张**：直接在卡片文件名上改（文本全选，扩展名自动保留，Enter 提交 / Esc 取消 / 失焦提交）<br>**多张**：批量模板对话框，`{name}` = 原名、`{n}` = 序号（自动补零） |
| 删除到回收站… | 走 Windows 回收站（可恢复），**不是永久删除** |

⚠️ 批量重命名**不会覆盖**同名文件；改完会清掉旧缩略图缓存并刷新列表。

## 七、搜索

右上搜索框，匹配：**文件名 / 标签名 / 地点名 / 品牌 / 机型 / 镜头**。

- 空格分隔多个词是 **AND**（同时满足）；
- `%` `_` 会被当字面量处理，不会变成通配符；
- 中文按子串匹配（不是分词索引），「日落」能搜到「海边日落」。

## 八、快捷键（图库模式）

| 键 | 作用 |
| --- | --- |
| `Ctrl + A` | 全选 |
| `F5` | 重扫当前范围 |
| `L` | 给选中的图打标签 |
| `Ctrl + O` | 打开文件 |
| `Esc` | 取消编辑 / 退出单图浏览 |
| 双击缩略图 | 进入单图浏览 |

## 九、几个容易踩的点

1. **外部新增的文件不会自己出现** —— 放完新图按 `F5`，或切一下窗口焦点（会自动重扫，2 秒限流）。
2. **「移除目录 / 删除图库」只删索引和缓存，绝不碰原图**。
3. **删除照片是进回收站**，不是永久删除。
4. **RAW 只能另存为，不能覆盖原文件**（8bit 替换 14bit Bayer 不可逆）。
5. **原地覆盖保存后缩略图会自动重取**（缓存键不含 mtime，靠 `ThumbSource.rev` 刷新）。
6. 图库里**没有标签**时，标签条整条不显示，选中块回到标题行右侧。
7. **人脸「人物」只在同一簇有 ≥3 张脸时才生成** —— 单张的人脸只进库，不建人物；名字由你自己起。
8. 侧栏目录读不到（权限/离线盘）会**明确报错**，不会显示成空目录。
