*本地照片管理，AI 全部离线跑。*

从 0.2.0 的「看图软件」长成了「照片管理器」：能建库、能搜索、能自动认出照片里有什么。

## 这一版最值得说的四件事

### ① 图库管理

把散在几个盘、几十个文件夹里的照片登记成册，之后按拍摄时间、地点、标签、相机找回来。

「浏览」和「入库」刻意分成两件事：**左键点文件夹只是预览**（不写索引、不生成缓存），
**右键「加入图库」才真正登记**。前者是随手看看的高频动作，不该往索引里塞东西。

- 多图库；智能图库（今年 / 本月 / 四星以上 / 只看 RAW）
- 标签、地点、评分、旗标；按格式 / 年份 / 相机 / 地点四联筛选
- 搜索：文件名、标签、地点、机身与镜头，多词 AND
- 批量：评分标记、旋转翻转、重命名、另存为、转格式、按 EXIF 摆正、复制/移动、打印、删除（进回收站）

### ② 本地 AI，不联网

- **自动打标**：CN-CLIP 零样本，111 条两级中文词表 + 互斥规则。单张约 0.43 秒。
- **人脸归类**：YuNet 检测 + SFace 128 维特征，两阶段聚类（0.55 出核心簇 → 0.50 并入），
  同一人物的照片自动归到一起，可以起名字。
- 模型随包附带，约 200 MB。**断网可用，照片不上传，也不调用任何在线接口。**

### ③ 绿色版

两种形态：

| 版本 | 数据目录 | 适合 |
| --- | --- | --- |
| 安装版 `..._x64-setup.exe` | `%LOCALAPPDATA%\PurePhotoExplorer` | 本机长期用，注册图片「打开方式」 |
| 绿色版 `..._portable.zip` | 解压目录下的 `data\` | 放 U 盘、换电脑、不想装 |

绿色版靠 exe 旁边一个空的 `portable` 文件识别。**整个文件夹拷走就是搬家** ——
索引、缩略图、人脸向量都跟着走，不用重新扫一遍。

### ④ 几处工程上的取舍

- **缩略图在源格式空间里降采样**：JPEG 用 DCT 缩放只解 1/64 的像素，2400 万像素的照片
  内存从 72 MB 降到 1 MB 出头。
- **缓存键 = blake3(卷编号 + 相对路径 + 大小 + 修改时间)**，不含盘符 ——
  移动硬盘今天 `D:` 明天 `E:`，缓存不该跟着失效。
- **写回文件一律「内存编码 → 临时文件 → 原子改名」**，断电或磁盘满都不会留下半个文件。
- **改 EXIF 前先辨类型和数量**：只有 `count==1` 且 `type∈{SHORT,LONG}` 才是内联值，
  否则值域存的是偏移量，写进去会毁掉指针。不确定就整份放弃。

## 支持格式

| 类别 | 扩展名 |
| --- | --- |
| 位图 | `jpg` `jpeg` `png` `bmp` `gif`（动图） `webp`（动图） `tif` `tiff` `avif` |
| 手机 / 苹果 | `heic` `heif` |
| 设计稿 | `psd`（合成图） |
| 相机 RAW | `cr3` `dng` `nrw` `raf` `rw2` `orf` `sr2` `srf` |
| 压缩包 | 直接浏览 `zip` `cbz` `7z` `rar` `cbr` `cb7` 里的图片 |

## 下载

- **绿色版**：`PurePhotoExplorer_1.0.0_win64_portable.zip`（约 216 MB，解压即用）
- **安装版**：`PurePhotoExplorer_1.0.0_x64-setup.exe`（NSIS，约 204 MB）

两个包都已内置 AI 模型与 DirectML.dll，不需要另外下载或安装运行库。

## 运行要求

- Windows 10 1809+ / Windows 11
- WebView2 Runtime（Win10/11 一般已内置）
- 磁盘：程序 + 模型约 280 MB

## 已知限制

- **RAW 只读**：只读取相机内嵌的 JPEG 预览，不支持写回原文件。另存为可以。
- **可覆盖写回的格式只有 `jpg` / `jpeg` / `png` / `bmp`**，其余一律走「另存为」。
- **压缩包内的图片只读**：旋转/编辑不会落进包里（那等于每次旋转都重写整个压缩包）。
- 绿色版不注册「打开方式」，想双击图片直接打开请用安装版。
- 编辑只支持 90° 整数倍旋转 + 按比例裁剪。任意角度微调只在预览层，不写回文件 ——
  否则要扩边或裁角，永久损失像素，且「所见非所得」。
