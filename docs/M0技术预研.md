### 安装命令（可复现）

```bash
# 1) 下载 rustup-init（12.7 MB）
curl -L --retry 8 --retry-all-errors -o rustup-init.exe https://win.rustup.rs/x86_64

# 2) 装 minimal profile（不装 rust-docs 等非必需组件）
./rustup-init.exe -y --default-toolchain stable --profile minimal --no-modify-path

# 3) 关键：换清华镜像，否则官方源极慢（实测 5 分钟无进展）
export RUSTUP_DIST_SERVER="https://mirrors.tuna.tsinghua.edu.cn/rustup"
export RUSTUP_UPDATE_ROOT="https://mirrors.tuna.tsinghua.edu.cn/rustup/rustup"
rustup default stable
```

### ⚠️ cargo 镜像踩坑（重要，可直接复用）

**清华镜像的 crates.io 索引只代理索引，不代理 crate 下载包**：

```bash
curl https://mirrors.tuna.tsinghua.edu.cn/crates.io-index/config.json
→ { "dl": "https://static.crates.io/crates", ... }   ← 仍指向被墙的源
```

表现为：索引解析成功但 `cargo build` 卡在 `failed to download from static.crates.io`，报
`transfer too slow: failed to transfer more than 10 bytes in 30s`。

**正确做法：用同时代理下载包的 rsproxy**，已写入 `~/.cargo/config.toml`：

```toml
[source.crates-io]
replace-with = 'rsproxy-sparse'

[source.rsproxy-sparse]
registry = "sparse+https://rsproxy.cn/index/"

[http]
timeout = 60
low-speed-limit = 1
multiplexing = true
```

### 另一个坑：rustup 中断会损坏工具链

强行终止卡住的 `rustup default stable` 后，会留下半安装状态：

```
error: missing manifest in toolchain 'stable-x86_64-pc-windows-msvc'
help: this may happen if the toolchain installation was interrupted
```

此时 `rustc --version` 仍能输出 1.99.0（因为二进制已落盘），但**任何 cargo 构建都会失败**。
修法：

```bash
rustup toolchain uninstall stable && rustup default stable
```

## 3. 待决策（阻塞 M0 后半段）

### 决策点：是否安装 MSVC C++ 工作负载（约 6–8 GB）

| 方案 | 优点 | 缺点 |
|---|---|---|
| **A. 装** | LibRaw 完整方案可用，M0 能验证真实性能数字，RAW 开发流程二期无阻碍 | 需下载 6–8 GB，占磁盘，可能需重启 |
| **B. 不装** | 立即可用 `rawler`（纯 Rust，无需 MSVC）跑通浏览功能 | M2 前仍需装；rawler 输出未去马赛克 Bayer，**只是临时方案** |

**我的建议：装。** 理由：

1. 本项目 RAW 是核心差异化功能，LibRaw 绕不过去 —— 早装早验证，还能拿到真实性能数字来校准文档里的估算
2. 用户已确认后续要做 RAW 完整开发流程，B 方案只是把 6–8 GB 的成本推后，不省事
3. 装完 LibRaw 后 M0 才能验证「内嵌预览 5–15 ms」这个关键假设是否成立

**若暂时不想装**，M0 可先用 rawler 验证接口设计（`RawPipeline` trait 已经定好，换实现不影响上层），但必须在 M2 前完成安装。

### 安装命令（方案 A）

```powershell
# 需要管理员权限
& "C:\Program Files (x86)\Microsoft Visual Studio\Installer\setup.exe" `
  modify `
  --installPath "C:\Program Files (x86)\Microsoft Visual Studio\18\BuildTools" `
  --add Microsoft.VisualStudio.Workload.VCTools `
  --add Microsoft.VisualStudio.Component.VC.Tools.x86.x64 `
  --add Microsoft.VisualStudio.Component.Windows11SDK.22621 `
  --includeRecommended
```

装完验证：

```bash
export PATH="$PATH:/c/Program Files (x86)/Microsoft Visual Studio/18/BuildTools/VC/Tools/MSVC"
cmake --version          # 需能输出版本
cl                      # 需能输出编译器版本
```
