# 「人物」分区 UI 设计（v2 · 2026-10-24 修订：侧栏改三块）

> 目标产品：PurePhotoExplorer 图库模式（深色默认）。本文件是**交接规格**，
> 所有数值都能直接落到 `manager.css` / 新建 `people.css`。

## 0. v2 变更（用户 22:20 定）

**侧栏固定三块：文件夹 / 图库 / 人像。「标签」分区删除。**

| 变化 | 说明 |
| --- | --- |
| 标签分区 | ❌ 侧栏不再列全部标签（130 个太长）。**筛标签仍走顶部 AI 标签条**，功能不丢 |
| 人像块 | 占原标签分区的位置，含「全部人像」置顶 + 人物行 |
| 图库块 | 选中图库后，行下展开一个「**人像 39**」子项 —— 点它进该图库的人像专栏 |
| 地点块 | 保留（有 GPS 数据时才出现），不占三块名额 |
| 行高 | 与现有密度对齐：**行高 28、头像 20 圆、名字 12、张数 11**（原稿的 40/28 太松） |

流程：`选图库 → 点它下面的人像 → 主区出人像专栏（人物墙）→ 点人 → 操作`。

## 1. 结构决策

| 决策 | 结论 | 理由 |
| --- | --- | --- |
| 分区位置 | 侧栏三块：**文件夹（在哪）/ 图库（哪个库）/ 人像（有谁）** | 从粗到细的筛选顺序，用户心智一致 |
| 人像入口 | ①图库行下的「人像 N」子项 ②人像块「全部人像」 | 前者=当前库的，后者=全库的；两个入口不冲突 |
| 人像块形态 | **单列行式**（头像 20 + 名字 + 张数），「全部人像」置顶 | 208px 宽放不下头像墙；行式一屏能看 8–10 人 |
| 人像专栏 | 主区 **6 列人物墙**，卡片 = 72 圆头像 + 名字 + 张数 | 一屏能看 12+ 人，比列表更像"人"; 也方便拖拽合并 |
| 详情入口 | 点人物卡 → 主区换成该人物的照片网格 | 与「侧栏换 scope、主区换内容」的既有模式一致 |
| 头像来源 | 前端用 `cover{imageId,x,y,w,h}` + 现成缩略图在 canvas 裁圆 | 后端不新增"裁剪头像"接口，省一次解码 |

| 状态 | 表现 |
| --- | --- |
| **未分析**（`faces=0`） | 侧栏该分区只显示一行说明 + `[开始分析]` 主按钮 + 「仅在本机运行，不上传」11px |

| **有人物** | 前 4 名 + 查看全部；未命名的显示 `未命名 ①`（①②③ 按张数降序编号，稳定键 = person id） |
| **选中** | 左侧 2px 强调条 + 弱底；主区切到该人物 |
| **没有人物** | 主区总览空态：「没找到可归纳的人」+ 说明「单张出现的人不会建人物」+ `[调低阈值重试]` |

| **小脸** | 卡片上角标 `低清`（`quality < 60` 时不作为封面，仍计入张数） |
| **合影多人** | 卡片左下角标 `2 人` |

## 4. 交互

- **命名**：点详情名字 → 变输入框（**文本全选**、Enter 提交、Esc 取消、失焦提交、非法字符换 `_`）——
  与卡片原地重命名同一套行为，别再造一套。
- **合并**：`合并到…` → 浮层（标题写明「谁的多少张脸会并入」）→ 单选列表（可搜索、未命名也可选）
  → 按钮文案变成 **「并入王芳」**（不是泛泛的"确定"）→ 底部一行 11px 风险说明。
  ⛔ 合并不可一键撤销，必须二次确认；主按钮不做危险色（危险色留给删除）。
- **拆分**：`[选择]` → 卡片进入多选（复用网格多选规则）→ 底部动作条 `已选 N 张脸 / [取消] [拆出来]`
  → 拆出后**新建未命名人物**并跳过去，方便立刻命名。
  ⚠️ 拆分单位是**脸**不是照片：合影里同一张图可能有多张脸，所以在「脸」视图下拆。
- **删除**：`⋯` → 删除人物（确认框写明「只解除归组，不会删除照片」）。
- **键盘**：`↑ ↓` 在侧栏人物间移动、`Enter` 进入、`F2` 改名、`Delete` 删除（确认）、`Esc` 退出选择态。
- **空操作保护**：一个人物都没有时，「合并到…」置灰。

## 5. 无障碍

- 侧栏人物列表容器 `role="listbox"`，行 `role="option"` + `aria-selected`；头像是装饰 `alt=""`。
- 选中/悬停不只用颜色：加左侧 2px 条（形状差异）。
- 对比度实测：`#eaeaef` on `#1c1c23` ≈ **13:1**；`#8e8eaa` on `#1c1c23` ≈ **5.4:1**（均过 AA）。
- 焦点环统一 `0 0 0 3px var(--pv-accent-ring)`，不用 outline 默认样式。
- 动作条按钮 24–26px 是桌面鼠标尺寸，可以接受；若将来支持触摸，再放大到 44。
