# 「设置」窗口 UI 设计（v2 · 2026-10-24）

> 用户定稿形态：**弹出独立设置窗口**（左侧分类树 + 右侧内容），不是下拉菜单。
> 参考 SumatraPDF 的设置窗口。本文件是交接规格。

## 1. 窗口

| 项 | 值 |
| --- | --- |
| 尺寸 | **720 × 560**，居中，不随主窗口缩放；最小 640×480 |
| 外观 | 背景 `--pv-bg-app`；标题栏 38（自绘，右侧 ✕）；左栏 196 + 0.5px 分隔；底栏 34 |
| 打开 | 菜单栏「设置」/ 快捷键 `Ctrl+,` / 图库 AI 齿轮（跳对应页） |
| 关闭 | ✕ / `Esc` / 点遮罩 |
| 保存 | **改动即时生效并自动保存**（底栏写明），没有「确定/取消」 |

## 3. 控件规格（全部自绘，现有令牌）

| 控件 | 规格 |
| --- | --- |
| 滑块 | 轨道 2px（`--pv-border-strong`）+ 已填充段 `--pv-accent`；拇指 12px 白底 + 2px accent 边；右侧数值 12px 右对齐（宽 40） |
| 下拉 | 高 **28**、圆角 6、`--pv-bg-input`、右侧 ▾；展开复用**现有 `ContextMenu`**（锚定下方，最多 13 行） |
| 开关 | **34 × 18**、圆角 9、钮 14；开 = accent 底 + 白钮靠右，关 = `--pv-border-strong` 底 + 灰钮靠左；**旁边始终有「开/关」文字** |
| 勾选框 | 16 × 16、圆角 4、选中 accent 底 + 白 ✓ |
| 按钮 | 高 28、左右 12、圆角 6；次级 = 描边；危险 = 红描边 + 红字（`#e24b4a` / `#f09595`） |
| 行间距 | 每项：标签 12 `--pv-text-secondary` + 6px + 控件；项间 18px |
| 说明文字 | 11 `--pv-text-tertiary`，控件下方 5px（如「调高更严：宁少勿错」） |

## 4. 规则

- ⛔ **不用原生控件**：`select` / `input[type=date]` 的弹层不跟随深色主题、会被窗口裁 —— 下拉走自绘
  `ContextMenu`；`input[type=range]` 是行内绘制，可以用但需重写样式。
- ⛔ **不做三级弹层**：分类树最多两级（组 → 页）；页内不再嵌套弹层，除下拉。
- **搜索框**（左栏顶部）：输入即过滤右侧为「命中项列表」，点结果跳到对应页并高亮该项。
- **危险项**：红色描边按钮 + `PromptDialog` 二次确认，文案写明「只删除人脸识别结果，不删除照片」。
- **键盘**：`Esc` 关闭；`↑↓` 在树里移动；`Tab` 在控件间；`Enter/Space` 触发开关与勾选。
- **无障碍**：树用 `role="tree"/"treeitem"` + `aria-selected`；开关用 `role="switch"` + `aria-checked`；
  滑块是原生 `<input type=range>`（保留键盘与读屏支持）。

## 5. 与现有入口的关系

| 现有 | 处理 |
| --- | --- |
| `SettingsPanel`（模态：打开方式 / 排序 / 幻灯片 / 关于） | **拆解并入本窗口**，原面板下线 |
| 图库标题右侧 AI 齿轮 | 保留，点开 = 本窗口的「AI 分析 · 打标与人脸」页 |
| `HelpPanel`（快捷键速查） | 保留，只留快捷键；「打开方式」的勾选迁到「文件类型」页 |
