# 阈值标定报告（2026-10-23，60 张样本）

## 方法

- 全库 279 张先统一打分（`tools/ai/dump_scores.py`，原始相似度，不含加成）。
- 按每图最佳分分层抽样 **60 张**（24 + 36 两批），人工核对每张 top-3 候选的对错。
- 二级 / 一级分别扫阈值，算「精度」与「有标签的图数」（覆盖）。

## 二级（最终推荐 0.42）

| 阈值       | 正确/发出     | 精度        | 有标签图         |
| -------- | --------- | --------- | ------------ |
| 0.36     | 103/174   | 59.2%     | 59/60        |
| 0.38     | 97/153    | 63.4%     | 52/60        |
| 0.40     | 79/105    | 75.2%     | 52/60        |
| 0.41     | 67/83     | 80.7%     | 52/60        |
| **0.42** | **56/66** | **84.8%** | **52/60**    |
| 0.43     | 36/39     | 92.3%     | 32/60 ← 覆盖跳水 |

⭐ **0.38 → 0.42 覆盖一直是 52/60 不变，精度从 63% 涨到 85%** —— 这段区间抬高阈值

"不花钱"：只删错标签，不丢图。到 0.43 覆盖才断崖（60→32），所以 0.42 是拐点。

## 一级（最终推荐 0.40）

| 阈值       | 正确/发出     | 精度        | 有标签图      |
| -------- | --------- | --------- | --------- |
| 0.36     | 62/153    | 40.5%     | 54/60     |
| 0.38     | 46/111    | 41.4%     | 50/60     |
| 0.39     | 34/59     | 57.6%     | 37/60     |
| **0.40** | **20/26** | **76.9%** | **23/60** |
| 0.41     | 13/13     | 100%      | 13/60     |

一级在 0.36~0.38 一直只有 40% 精度（模型分不出 15 个类目里哪个对），

必须抬到 0.40 才可用；代价是只有 23/60 张图有可用的"一级"标签。

## 全库实测（280 张，二级 0.42 / 一级 0.40）

- 有标签 **168/280（60%）**，空 112 张（模型确实认不出，主要是星空/抽象/文档类）
- 平均：二级 0.6 个/图、一级 0.7 个/图

## 与旧配置对比

| 配置          | 二级精度    | 二级/图    |
| ----------- | ------- | ------- |
| 0.38（旧）     | 63%     | 7.8     |
| 0.40        | 75%     | 2.5     |
| **0.42（新）** | **85%** | **1.3** |

## 结论

精度和数量不可兼得。85% 精度意味着"标签基本可信"，代价是每张图平均不到 1 个二级标签。

如果要更多标签，唯一出路是换更强模型（H/14 在标定后精度 76.5%，比 B/16@0.40 的 75% 略好、

比 B/16@0.42 的 85% 差），或改用 caption 路线（先描述再抽词）。
